# 控制台

本机网页，查看大脑和语音的运行状态、今天的对话和费用、所有配置参数。**目前只读**：不改任何数据，不调用模型。

## 启动

```bash
# 第一次，或者前端代码改动之后：构建前端
cd console/web && npm install && npm run build && cd ../..

# 启动控制台（独立进程，不依赖大脑和语音是否在运行）
.venv/bin/python -m apps.console          # 默认端口 8770，可用 --port 改
```

终端会打印 `http://127.0.0.1:8770/login?token=...`，用这个链接打开。令牌**每次启动都会重新生成**，
控制台重启后旧页面会提示"登录已失效"，用新链接重新打开即可。

## 页面

| 页面 | 内容 |
| --- | --- |
| 总览 | 大脑、语音各自的状态；今天的轮数、会话、出错、播放结果；今天的费用（已知 / 参考估算 / 待核对分开）；需要注意的事项 |
| 设置 | 按分组的标签页；每个参数的已保存值、来源（.env / 默认）、状态；点开看说明、类型、范围、各进程正在用的值 |

总览每 5 秒刷新，设置每 10 秒刷新（页面不在前台时不刷新）。

### 状态的含义

| 进程状态 | 含义 |
| --- | --- |
| 运行中 | 大脑的 `/status` 有响应；语音的心跳在 15 秒以内 |
| 连不上 | 大脑没有响应：可能没启动，也可能卡住了，所以不叫"已停止" |
| 心跳过期 | 语音的状态文件太旧：可能崩溃、被强制结束，或者卡住了 |
| 已停止 / 未启动 / 状态不可读 | 见 [SETTINGS.md](SETTINGS.md) 的"运行状态" |

| 参数状态 | 含义 |
| --- | --- |
| 已生效 | 进程正在用的值和已保存的一样 |
| 等待重启 | 已保存，但进程还在用旧值 |
| 不知道 | 读取它的进程没在运行（或者两个进程里有一个不知道） |
| 下次启动时读取 | 只有按需运行的程序（文字 CLI）读取 |

### 费用

- **已知**：按服务端用量或接口返回的费用计算；
- **参考估算**：旧 Omni 内置 ASR 的估算，不计入已知；
- **待核对**：缺少最终用量或价格的请求，**不能当成零**；
- 平均每轮 = 今天的已知费用 ÷ 今天交给大脑的轮数。分子也包括没有交给大脑的部分（Jev、ASR），
  所以它是"每轮对话的综合成本"，不是"每次大脑请求的成本"。

"今天"按本机时区的零点计算。

## 安全

只监听 `127.0.0.1` 还不够：浏览器里打开的任何网页都能向本机发请求。所以：

| 措施 | 防的是什么 |
| --- | --- |
| 启动令牌换 cookie（`HttpOnly`、`SameSite=Strict`），令牌不留在地址栏 | 没有令牌的人（包括别的网页）读不到任何数据；**读取的接口和页面本身也要登录** |
| Host 只接受 `127.0.0.1` / `localhost` | DNS rebinding：恶意域名解析到 127.0.0.1 后，以"同源"身份读取数据 |
| 改变状态的请求必须带同源 `Origin` 和 `X-Alpha-Console: 1` | 跨站表单、跨站请求（D4 起有写入接口时生效，现在就已经开启） |
| CSP 只允许自己的脚本和样式；禁止被嵌入；不发送 Referer | 注入的脚本、点击劫持、链接把地址泄露出去 |
| 数据库用 SQLite `mode=ro` 打开 | 控制台从结构上写不了存档、费用、操作和记忆；文件不存在也不会被创建 |
| 接口里没有密钥的值 | 密钥只显示"已设置 / 未设置"（测试会检查响应里不出现任何密钥） |
| 存档和工具结果按纯文本显示 | 邮件、网页内容里的 HTML 不会被执行（React 默认转义，不使用 `dangerouslySetInnerHTML`） |
| 页面和数据不缓存（`Cache-Control: no-store`） | 对话内容留在浏览器缓存里 |

## 开发前端

```bash
.venv/bin/python -m apps.console          # 先启动控制台
cd console/web && npm run dev             # Vite 开发服务器，127.0.0.1:5173，接口转发到 8770
```

把终端里打印的登录链接的端口 8770 换成 5173 打开一次，拿到 cookie。
`node_modules/` 和构建产物 `dist/` 不进 git。

## 代码

| 文件 | 作用 |
| --- | --- |
| `apps/console.py` | 入口：生成令牌、查询大脑 `/status`、启动 uvicorn |
| `console/server.py` | 路由和安全检查 |
| `console/data.py` | 只读数据：总览、设置的计算 |
| `console/web/` | 前端（Vite + React + React Router） |
| `tests/test_console.py` | 登录、Host、来源检查、路径穿越、只读、密钥不泄露、总览和设置的计算 |
